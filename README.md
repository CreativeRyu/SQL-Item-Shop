# SQL Item Shop

<img width="742" height="444" alt="grafik" src="https://github.com/user-attachments/assets/392e1355-22e7-4d03-b455-0447112dee88" />


SQL Item Shop is a cozy pixel-art SQL learning game where players explore a small RPG-style shop and learn SQL interactively through quests, progression, and unlocks.

Write SQL queries, complete missions, earn money, and unlock new features like the SQL Notebook while managing and analyzing the shop's database.

The game combines:

Pixel RPG atmosphere\
Interactive SQL learning\
Shop simulation data\
Quest progression\
Unlockable gameplay systems

Built with:

Vanilla JavaScript\
SQLite in the browser using sql.js\
CodeMirror\
Custom pixel-art UI

Features:

SQL missions and progression\
Real database-driven shop items\
Dynamic SQL output tables\
RPG-inspired quest log\
Shopkeeper dialogue & hints\
Unlockable notebook system (WIP)\
Pixel-art shop environment

The goal is to make learning SQL feel like progressing through a cozy RPG adventure instead of a traditional tutorial.
